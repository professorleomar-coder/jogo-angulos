# 📐 Jogo dos Ângulos (60 Questões - Arquivo Único)

Jogo educativo minimalista e direto em **um único arquivo** ([`index.html`](file:///C:/Users/profe/.gemini/antigravity/scratch/jogo-angulos/index.html)), sem dependências externas.

---

## 🎯 Características
- **100% Contido em um só arquivo**: Todo o HTML, CSS e JavaScript estão no [`index.html`](file:///C:/Users/profe/.gemini/antigravity/scratch/jogo-angulos/index.html).
- **Foco Visual**: Mostra apenas a imagem com o ângulo, sem textos explicativos e sem valores numéricos de medidas ou graus.
- **60 Questões Balanceadas**:
  - 20 Ângulos Agudos
  - 20 Ângulos Retos
  - 20 Ângulos Obtusos
- **As 3 Opções de Resposta**:
  - 📐 **Ângulo Agudo**
  - ⏹️ **Ângulo Reto**
  - 🪭 **Ângulo Obtuso**
- **Atalhos Rápidos**:
  - Teclas `1`, `2` ou `3` para escolher a opção.
  - Tecla `Enter` ou `Espaço` para ir para a próxima questão.
